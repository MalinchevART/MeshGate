MeshGate — комплект за пренос
==============================

Това е цялата папка на проекта (код + git история + backups с данните).

На другия компютър:
  1. Разархивирай zip-а където искаш да живее проектът.
  2. Двоен клик: meshgate\deploy\install-meshgate.cmd
     — проверява какво липсва (Git, Docker), ПИТА за разрешение,
       инсталира, вдига стека и чака да е здрав.
  3. (по избор) Върни данните от старата машина:
     meshgate\deploy\meshgate.cmd → избор 14 (Restore от backup)
     и избери файл от meshgate\deploy\backups\.
     Връща правилата, потребителите, мостовете и канала за известия.
  4. Отвори http://localhost/ — входът е в deploy\.env
     (ако .env не е включен в комплекта: инсталаторът генерира нов
      и показва началната парола).

Управление на всичко (стек, рестарт на услуга, тестове, backup,
нов комплект): meshgate\deploy\meshgate.cmd

Бележки:
- Ако ползваш git workflow с два компютъра — виж също MeshGateProject\sync\
  (bundles по проект); този комплект е начинът „всичко наведнъж“.
- Волумите на Docker (pg_data) не се пренасят — данните пътуват само
  през backup dump файловете.
